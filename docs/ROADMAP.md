# Roadmap – WakeCoach

התוכנית המפורטת לכל שלב: [PLAN.md](PLAN.md).

| גרסה | נושא | דרישות |
|---|---|---|
| **0.1** ✅ | ליבה: התראה אמינה, ממשק ארגונומי, 5 פרופילים, אתגרים (חשבון/משפט/ניעור/צעדים), משוב 1-5, "מה חשוב מחר", תזכורת שינה | 1, 2, 3, 5, חלק מ-6 ו-7 |
| **0.2** | **ממשק + תזכורות יום**: ערכת נושא בהירה/כהה/לפי המערכת, גלגלת לבחירת שעה, ימים בכפתורים עגולים, סוג התראה "תזכורת" (לגן, לצאת מהעבודה, להתקשר) | 1, תזכורות יום |
| **0.3** | **אמינות במכשירי סמסונג + אשף הרשאות**: בקשה להחרגה מאופטימיזציית סוללה, הסבר על "אפליקציות רדומות" של סמסונג, מסך בדיקה "האם ההתראות שלי יצלצלו?", התראת בדיקה בלחיצה | אמינות (קריטי לשעון מעורר) |
| **0.4** | **אודיו ותוכן**: בחירת צליל לפי חשיבות, שעה, התראות היום ואירועים ביומן; ספריות צלילים חופשיות; הסלמה לצלילי מערכת (שיחה, הודעה); הקלטות אישיות ובני משפחה; "ראיון אישי"; משפטי פילוסופיה, אמונה, עובדות ובדיחות + TTS | 6, 7 (תוכן וקולות) |
| **0.5** | **למידה, התאמה ושומר התראות**: חיישנים בחלון מצומצם סביב ההתראה, זמן הירדמות, זיהוי חזרה לשינה, `AdaptiveEngine`, אנטי-שאננות, מסך התקדמות ופרגון, Alarm Guard (התראה חסרה או כבויה, כולל תזכורות יום), "דלג פעם אחת" | 4, 7 (חיישנים), 8 (חזרה לשינה), 13, שומר התראות |
| **0.6** | **טקטיקות הפתעה**: שיחה מדומה (צליל חיוג, מענה, ניתוק, אזהרה), סיפור הפוך, רמאות בשעה, תרגילי נשימה, "קום ועמוד", דיאלוג קולי, בדיקת "עדיין ער?" | 8, 9, 10, 11, 12 |
| **0.7** | **Wake Buddies**: שיתוף סטטוס הקימה עם חברים מאושרים, push כשלא קמת, כפתור "תעיר" (Firebase) | שיתוף מצב |
| **1.0** | **שחרור**: onboarding, סריקת קוד QR בחדר אחר (אתגר), גיבוי ושחזור, פרטיות, אייקון ומיתוג, Google Play | השלמות |
