# WakeCoach – השעון ששולח אותך לישון

שעון מעורר לאנדרואיד שמעודד אותך, מציב לך אתגרים, לומד את ההרגלים שלך ומתאים את עצמו אליהם כדי שתקום בזמן. גם בלילה הוא שולח אותך לישון בזמן.
התוכנית המלאה, בחמישה שלבים: [docs/PLAN.md](docs/PLAN.md).

## מה כבר בנוי (שלב 1 – ליבה)
- **ממשק ארגונומי**: ספרות ענק שמתאימות את עצמן לרוחב המסך, כפתורים של 64dp ומעלה, ופעולות ראשיות בתחתית המסך בצד האגודל (ימין או שמאל, לפי ההגדרות).
- **5 פרופילים**: עדין, מאוזן, קשוח, חייל (בלי נודניק), ישנוני כבד.
- **אתגרים לכיבוי**: חשבון לפי רמת קושי, הקלדת משפט, ניעור, צעדים (חיישן צעדים, ואם אין חיישן או הרשאה אז ניעור).
- **מסך צלצול**: מוצג מעל מסך הנעילה, נדרשת החלקה ארוכה כדי לכבות, כפתור הנודניק קטן ורחוק מהאגודל, ונודניקים מתקצרים.
- **צליל**: עולה בהדרגה (crescendo) לפי הפרופיל, עם רטט. אם צליל ההתראה לא נטען, השעון עובר לצלצול רגיל ואחר כך לצליל התראה.
- **"מה חשוב לך מחר?"**: נשאל בערב. בבוקר התשובה מוצגת ונקראת בקול (TTS).
- **משוב 1-5**: מצב רוח, קושי הקימה ועייפות מיד אחרי הקימה, ודגימת עייפות נוספת אחרי 25-40 דקות.
- **משפטי עידוד מהנתונים שלך**: למשל "3 בקרים ברצף בלי נודניק", או השוואה בין בקרים עם נודניק לבקרים בלעדיו.
- **תזכורת שינה**: מחושבת לאחור משעת ההשכמה ומיעד השינה.
- **תשתית לשיתוף המצב עם חברים מורשים (שלב 5)**: מכונת מצבים של סטטוס הקימה ומודל הרשאה דו-צדדי. החיבור ל-Firebase ייבנה בשלב 5.
- עברית ואנגלית, כולל RTL.

## מבנה
```
core/   לוגיקה ב-Kotlin טהור (בלי Android) + בדיקות: פרופילים, אתגרים, חישוב זמנים, סטטיסטיקה, הודעות, שיתוף
app/    אפליקציית Android: Compose, Room, DataStore, AlarmManager, Foreground Service
```

## התקנה ועדכונים
כל push ל-`main` נבנה ב-GitHub Actions (`.github/workflows/build.yml`) ומתפרסם כ-Release עם `wakecoach.apk`.
- **התקנה ראשונה:** מורידים את `wakecoach.apk` מ-https://github.com/yanivmalka/wakecoach/releases/latest ומתקינים.
- **עדכונים:** האפליקציה בודקת עדכונים בפתיחה (לכל היותר פעם ב-6 שעות), ויש גם כפתור "בדוק עדכונים" בהגדרות.
- **חתימה:** הבנייה דורשת את ה-Secrets `SIGNING_KEYSTORE_B64` ו-`SIGNING_PASSWORD`. כל הגרסאות חתומות באותו מפתח, ולכן עדכון מותקן מעל הגרסה הקיימת.
- **כשל בבנייה:** נפתח issue בשם "CI build failed" עם הלוג, והוא נסגר לבד כשהבנייה הבאה מצליחה.

## בנייה מקומית
דרוש Android SDK (למשל דרך Android Studio).
```
./gradlew :core:test          # בדיקות הלוגיקה, לא דורש Android SDK
./gradlew :app:assembleDebug  # דורש ANDROID_HOME או local.properties עם sdk.dir
```
המודול `app` נכלל בבנייה רק כשנמצא Android SDK.

Gradle 8.14.3 צריך לרוץ על JDK בגרסה 17 עד 24. מומלץ JDK 21, שמגיע עם Android Studio (לא JDK 25).
ב-Android Studio מגדירים את זה ב-Settings → Build, Execution, Deployment → Build Tools → Gradle → Gradle JDK.

## בדיקה ידנית מומלצת
1. מגדירים התראה לעוד 2 דקות, נועלים את המסך ומחכים שהיא תצלצל מעל מסך הנעילה.
2. מצב Doze: `adb shell dumpsys deviceidle force-idle` ואז מחכים להתראה.
3. אתחול המכשיר: ההתראות צריכות להיות מתוזמנות מחדש.
4. בודקים כל פרופיל ואתגר, וגם את הממשק במצב שמאלי.
